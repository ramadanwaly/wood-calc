# حاسبة تكعيب الخشب

تطبيق ويب بسيط لحساب حجم قطع الخشب وتكلفتها. يعمل على الهاتف والكمبيوتر، ويمكن تثبيته كتطبيق ويب على الأجهزة التي تدعم ذلك.

## المميزات

- إضافة قطع مع اسم اختياري وأبعاد الطول والعرض والتخانة.
- استخدام السنتيمتر أو المليمتر أو البوصة لكل بُعد.
- حساب حجم القطع بالمتر المكعب والإجماليات تلقائيًا.
- احتساب نسبة الهالك وسعر المتر المكعب.
- إنشاء ملف PDF للكشف ومشاركته عبر قائمة المشاركة في الأجهزة المدعومة.
- تصدير الكشف والإجماليات إلى PDF عبر نافذة الطباعة في المتصفح.
- حذف قطعة أو مسح الكشف بالكامل.
- حفظ الكشف والإعدادات في المتصفح تلقائيًا.
- دعم العمل دون اتصال بعد فتح التطبيق وتحميل ملفاته.

## التشغيل محليًا

يمكن فتح `index.html` في المتصفح لمعاينة التطبيق. ولتجربة خصائص التطبيق التقدمي، مثل Service Worker والعمل دون اتصال، شغّله عبر خادم محلي أو انشره على استضافة تدعم HTTPS.

## النشر على GitHub Pages

1. ارفع ملفات المشروع إلى مستودع على GitHub، مع وجود `index.html` في المجلد الرئيسي للمستودع.
2. افتح صفحة المستودع، ثم اختر **Settings → Pages**.
3. ضمن **Build and deployment**، اختر **Deploy from a branch**.
4. اختر فرع `main` ومجلد `/(root)`، ثم اضغط **Save**.
5. انتظر اكتمال النشر، ثم افتح الرابط الذي يظهر في إعدادات Pages وشاركه مع المستخدمين.

بعد أي تحديث ترفعه إلى الفرع والمجلد المحددين، سيعيد GitHub Pages نشر الموقع تلقائيًا.

## تصدير الكشف إلى PDF

اضغط **تصدير / طباعة PDF** أسفل الإجماليات. في نافذة الطباعة، اختر **حفظ كملف PDF** (قد يختلف اسم الخيار حسب المتصفح والجهاز)، ثم اختر مكان حفظ الملف. ستظهر في الملف قائمة القطع والإجماليات دون أزرار الإدخال والحذف.

## إرسال الكشف إلى WhatsApp

اضغط **مشاركة ملف PDF عبر WhatsApp** أسفل الإجماليات. ينشئ التطبيق ملف PDF يتضمن تفاصيل القطع والإجماليات، ثم يعرض قائمة المشاركة في الأجهزة والمتصفحات التي تدعم مشاركة الملفات؛ اختر WhatsApp والمحادثة ثم أرسل الملف. لا يرسل التطبيق الملف تلقائيًا.

إذا لم يدعم المتصفح مشاركة الملفات، فسيُنزل ملف PDF إلى الجهاز لتتمكن من إرفاقه يدويًا في WhatsApp.

## بيانات المستخدمين

يحفظ التطبيق الكشف والإعدادات في `localStorage` داخل المتصفح. لذلك تكون البيانات مستقلة بين متصفحات وأجهزة المستخدمين، ولا يحتاج الاستخدام إلى إنشاء حساب أو قاعدة بيانات.

- لا تنتقل البيانات تلقائيًا بين أجهزة الشخص نفسه.
- إذا استخدم عدة أشخاص المتصفح نفسه على الجهاز نفسه، فسيشتركون في بياناته المحفوظة.
- قد تُفقد البيانات عند مسح بيانات الموقع أو المتصفح؛ لا تستخدم هذا التخزين بديلًا عن النسخ الاحتياطي.

## ملفات المشروع

- `index.html`: واجهة التطبيق.
- `style.css`: التنسيق ودعم الشاشات المختلفة.
- `app.js`: الحسابات وإدارة القطع والحفظ المحلي.
- `manifest.json`: بيانات تثبيت التطبيق.
- `sw.js`: تخزين ملفات التطبيق للعمل دون اتصال.
